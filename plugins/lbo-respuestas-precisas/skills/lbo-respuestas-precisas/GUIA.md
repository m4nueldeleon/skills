# Respuestas claras: 8 reglas para tu IA

Manuel de León · Recursos de IA para negocios · 8 de septiembre de 2026

Una skill para definir el resultado, limitar el relleno y pedir evidencia cuando hace falta.

## Qué resuelve

Cuando pides “ayúdame con marketing”, la IA tiene demasiado espacio para interpretar. Esta skill de respuestas claras te ayuda a trabajar con un encargo concreto y a recibir una respuesta proporcionada. Esta es una adaptación pública nueva de ocho reglas para cumplir la promesa de respuestas precisas del reel; no requiere acceso a las herramientas privadas de Manuel.

El objetivo es ahorrar lectura y repeticiones. El consumo de tokens depende de la herramienta, del historial y del trabajo; no hay un porcentaje de ahorro garantizado.

## Antes de empezar

Prepara cinco datos: resultado final, contexto útil, material disponible, límites y formato. No pegues toda la historia de tu negocio si solo necesitas mejorar un asunto de correo.

```text
Usa LBO para resolver este encargo.

Resultado final: [qué necesito tener terminado].
Contexto indispensable: [lector, negocio y situación].
Material disponible: [texto, archivo o datos].
Límites: [extensión, fecha, presupuesto o cosas que no se pueden cambiar].
Formato: [tabla, correo, lista de decisiones, archivo].
Criterio de aceptación: [cómo sabremos que quedó bien].

Primero entrega el resultado. Explica solo lo necesario para usarlo.
Si falta un dato que cambia la decisión, pregúntalo.
Si puedes avanzar con una suposición de bajo riesgo, indícala.
No inventes fuentes, resultados de herramientas ni trabajo terminado.
```

## Ejemplo para tu negocio

“Necesito un mensaje de WhatsApp de máximo 80 palabras para clientes que pidieron una cotización y no respondieron. Vendemos cocinas a medida. Quiero recuperar la conversación sin regalar un descuento. Conserva un tono amable. Termina con una pregunta que se responda en una frase”.

Eso permite una respuesta útil. “Hazlo más profesional” no explica qué hay que mejorar.

## Cuando la respuesta queda corta

Pide una ampliación específica: “Agrega tres objeciones frecuentes”, “Explica el cálculo” o “Dame dos versiones con distinto tono”. Breve no significa incompleto. En una decisión delicada, conservar una limitación vale más que reducir diez palabras.
