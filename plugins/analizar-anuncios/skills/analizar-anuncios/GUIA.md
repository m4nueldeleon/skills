# Analiza anuncios y crea tu propia versión

Manuel de León · Recursos de IA para negocios · 8 de septiembre de 2026

Una skill para estudiar mensajes, ofertas y pruebas sin copiar una marca.

## Instálala en 3 pasos

Sigue el asistente de instalación: https://manueldeleonm.com/recursos/analizar-anuncios/

Funciona en Claude (app o web), en Claude Code y, copiando las instrucciones, en ChatGPT o Gemini. El código de esta skill es público: https://github.com/m4nueldeleon/skills

## Qué observar

Un anuncio visible no demuestra rentabilidad. Que siga activo es una señal para investigar, no una prueba de ventas. Tu tarea es entender a quién habla, qué problema presenta, cómo muestra el producto y qué pide hacer.

Esta skill pública permite analizar material que tienes permiso de usar. Trabaja con enlaces accesibles, texto o capturas que proporciones. No ofrece acceso a datos privados ni garantiza extraer contenido de todas las plataformas.

## Recopila cinco anuncios

Guarda enlace, fecha de revisión, anunciante, formato, gancho inicial, promesa, prueba mostrada y CTA. Si puedes ver cuándo inició, anota esa fecha. Si no, escribe “no disponible”.

## Prompt para comenzar

```text
Usa la skill analizar-anuncios con estos cinco anuncios.
Mi negocio: [descripción].
Mi cliente: [perfil y situación].
Mi oferta real y condiciones: [detalle].
Pruebas que sí tengo: [demostraciones o testimonios autorizados].
Anuncios y material accesible: [enlaces o texto].

Separa observaciones verificables de hipótesis.
Analiza gancho, problema, mecanismo, prueba, oferta y CTA.
No afirmes que un anuncio vende por llevar tiempo activo.
Después crea tres conceptos propios para mi oferta.
Incluye guion de 30 segundos, toma visual, texto en pantalla
y una sola llamada a la acción por concepto.
No copies el guion, logotipo ni identidad de la competencia.
```

## Tu primera prueba

Elige un problema del cliente, dos ganchos y una oferta. Mantén el resto constante para poder comparar. Define antes qué cuenta como resultado: conversación calificada, registro o compra real.

Anota inversión, resultados y periodo. El costo por resultado divide el gasto entre resultados válidos. No confundas clics con clientes. Cuando el tráfico llegue a una página, comprueba que el precio, la promesa y la siguiente acción coincidan con el anuncio.

## Qué revisar cada semana

Descarta mensajes que atraen curiosidad sin intención de compra. Conserva lo que genera conversaciones adecuadas y mejora una variable a la vez. Guarda también los anuncios que no funcionaron y lo que aprendiste; esa evidencia evita repetir una mala apuesta.
